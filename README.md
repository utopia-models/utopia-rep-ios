# utopia-rep-ios — the rep app's iOS shell (utopia-models/knowledge#9978, PLAN-412 P8)

A Capacitor 8 wrapper of the rep PWA. It loads the deployed rep app (`server.url` in `capacitor.config.json`,
`https://cleaning.utopiamodels.ai/rep`) and adds what a browser tab cannot do: APNs push, the native camera
and GPS (`@capacitor/push-notifications`, `@capacitor/camera`, `@capacitor/geolocation`). If the page cannot
load, `www/offline.html` is shown and reloads the app when signal returns. The PWA is still how reps use the
app today; this shell is the App Store path and blocks nothing.

The Xcode project (`ios/App`, Swift Package Manager, no CocoaPods) is generated by `npx cap add ios` and
committed; `npx cap sync ios` refreshes `ios/App/App/public` and `capacitor.config.json` from this folder.
It builds on Linux as far as `cap sync`; compiling needs macOS, so CI does it (`.github/workflows/ios.yml`). The
repo is public because hosted macOS runners are free only on public repos (the org's hosted minutes are frozen);
the rep app itself lives in the private `utopia-models/cleaning`.

| job | needs | does |
|---|---|---|
| `simulator` | nothing | `xcodebuild … -sdk iphonesimulator CODE_SIGNING_ALLOWED=NO build`, uploads `App.app` |
| `testflight` | repo secrets `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8`, `APPLE_TEAM_ID` | archive with automatic signing through the API key, export with `destination=upload`; skips with a notice while the secrets are missing |

## Using the native features from the web app

Inside the shell, `window.Capacitor?.isNativePlatform()` is true and the plugins are on
`window.Capacitor.Plugins` (`Camera.getPhoto`, `Geolocation.getCurrentPosition`,
`PushNotifications.requestPermissions` / `register`, whose `registration` event carries the APNs token).
In Safari the same page keeps using `<input capture>`, `navigator.geolocation` and Web Push, so one code path
per feature checks `isNativePlatform()` first.

## From enrolled to TestFlight (in order)

1. **Apple Developer Program, organization** — Utopia Models, Inc., enrolled with its D-U-N-S number by the
   Apple Account that already signed the Apple Developer Agreement; $99 a year. The enrollment state and its
   values are on utopia-models/knowledge#9978 (a private repo), not here.
2. **App Store Connect API key** — Users and Access → Integrations → App Store Connect API → Team Keys →
   generate with the *App Manager* role. Store the key id, issuer id and the `.p8` contents in Infisical
   (`utopia/CLEANING_ASC_KEY_ID`, `CLEANING_ASC_ISSUER_ID`, `CLEANING_ASC_KEY_P8`) and the team id as
   `utopia/CLEANING_APPLE_TEAM_ID`, then set the four repo secrets from them
   (`gh secret set ASC_KEY_P8 --repo utopia-models/utopia-rep-ios < key-file`; never on a command line).
3. **The app record** — App Store Connect → Apps → + → iOS, name *Utopia Rep*, bundle id
   `com.utopiacleans.rep` (register it under Identifiers first with the Push Notifications capability),
   SKU `utopia-rep`. The API cannot create the record; the browser can.
4. **Run `ios`** (`gh workflow run ios --repo utopia-models/utopia-rep-ios --ref main`). The `testflight` job's last
   line names the build number; it appears under TestFlight after processing (about 15 minutes).
5. **Install** — add the tester under TestFlight → Internal Testing; the TestFlight app on the iPhone installs it.

The listing text for the first submission is in `app-store/listing.md`.
